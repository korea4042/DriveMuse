# 실기기 검증

1. 같은 서명으로 기존 0.2.0에서 업그레이드: 규칙·기록 유지, handoff가 청취 기록으로 변환되지 않는지 확인.
2. 설문 선택/미응답/ANY/NONE, 이전·건너뛰기, 강제 종료 후 재개, 제외 충돌 확인.
3. Firebase 미설정·동의 거부·할당량·타임아웃 시 동일 제외 조건으로 로컬 추천. Gemini 실행에는 개인 설정 필요.
4. 설문/규칙/계정 변경 및 전체 초기화 중 늦은 추천이 돌아와도 적용되지 않는지 확인.
5. 3곡 표시와 재시작 복원. 재시작 후 음악 앱에 명령을 자동 전송하지 않아야 함.
6. 위치 거부/오래된 위치/경계·저정확도, 날씨 지역/시각 불일치 및 키 누락을 확인.
7. 집·회사 영역 저장과 삭제, 백업 제외와 원시 이동 경로 미기록 확인.
8. 알림 접근 동의 후 YTM 상태만 진단. 일반 알림 내용을 저장하지 않고 학습 수준 L0를 유지해야 함.
9. 명시 평가의 동일 곡 개정은 덮어쓰기. 설문은 유지한 채 학습 삭제; 전체 초기화는 설문/영역도 삭제.
10. 운전 모드에서 설정·입력·삭제가 차단되는지, 큰 글꼴/TalkBack 확인.
11. G0 표를 별도 작성: 기기/OS/YTM 버전, mediaId와 videoId 대응, PLAYING·position 신뢰도, 다음/중단 원인, 임의 곡 명령 수용. 통과 전 G2/G3 활성화 금지.
